From the web-app terminal, run npm.cmd run audio:download to download and name all eight configured music/effect files automatically. Run npm.cmd run audio:check to verify them offline. Refresh the browser after installation, then click anywhere or use Enable music in the footer. Music continues through the ready screen, countdown, gameplay and results. The footer button and Operator controls also allow mute and retry.

Music: idle.mp3 (waiting/results), background.mp3 (normal game), frenzy.mp3 (five-second frenzy).
Effects: start.wav (3-2-1), hit.wav, wrong.wav, warning.wav (loops during the normal round's last ten seconds), gameover.wav (game over/time-out).

Credits and source links are in CREDITS.txt. Keep the music attribution with the app. Downloaded Mixkit WAVs are excluded from git because their license prohibits distribution with source files; each teammate runs the downloader locally. If a provider is unavailable, existing valid files are kept and missing files are listed. Missing effects use placeholder tones; missing music stays silent. See web-app/README.md.
